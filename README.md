# سِراج | SIRAJ

قصص ما قبل النوم، أبطالها أطفالك. تطبيق ويب يعمل بدون إنترنت، وكل البيانات على جهاز الأسرة فقط.

من **WAMD ARC** · [wamdarc.com](https://wamdarc.com)

## الملفات
| الملف | وظيفته |
|---|---|
| `index.html` | الواجهة والتصميم |
| `app.js` | منطق التطبيق: الأطفال، قصة اليوم، القارئ، الصوت، النسخة الاحتياطية |
| `art.js` | رسومات الشخصيات والمشاهد |
| `stories.js` | مكتبة القصص (قوالب بالأسماء) |
| `sw.js` | تشغيل بدون إنترنت. **غيّر رقم `CACHE` مع كل تحديث** |
| `manifest.webmanifest` | اسم التطبيق وأيقونته على الشاشة الرئيسية |
| `CNAME` | النطاق `siraj.wamdarc.com` |

## النشر
1. أنشئ مستودع `bsshfi/siraj` وارفع كل الملفات.
2. Settings ← Pages ← Branch: `main` / root.
3. في Spaceship أضف سجل CNAME: `siraj` ← `bsshfi.github.io`.

## إضافة قصة
أضف عنصرًا في `STORIES` داخل `stories.js`:
- `{n}` اسم البطل
- `{أ|ب}` أ للولد، ب للبنت
- `[[ ... ]]` يظهر فقط مع وجود أطفال مشاركين
- `{fr}` أسماء المشاركين
- `{{أ|ب|ج}}` حسب المشاركين: ولد واحد | بنت واحدة | أكثر من واحد

المشاهد المتاحة: `desert` `sea` `space` `garden` `home` `school` `night`
