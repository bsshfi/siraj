# سِراج | SIRAJ

قصص ما قبل النوم، أبطالها أطفالك. تطبيق ويب يعمل بدون إنترنت، ويربط جوال وليّ الأمر بتابلت الأطفال.

من **WAMD ARC** · [wamdarc.com](https://wamdarc.com)

## الملفات
| الملف | وظيفته |
|---|---|
| `index.html` | الواجهة والتصميم |
| `config.js` | **رقم الإصدار، ورابط السيرفر، ومفتاح الإشعارات العام** |
| `app.js` | منطق التطبيق، وقواعد الليل (عدد القصص، القفل) |
| `play.js` | سماء سِراج، والألعاب (تلوين، أحجية، أسئلة)، والتسجيل بالصوت |
| `sync.js` | ربط العائلة والتشفير والمزامنة |
| `art.js` | رسومات الشخصيات و١٥ مشهدًا |
| `stories.js` `stories-2.js` | مكتبة القصص (٥٠ قصة + ٣ مناسبات) |
| `sw.js` | العمل بدون إنترنت، والتحديث التلقائي، والإشعارات |
| — | الإدارة والإشعارات من admin.wamdarc.com |
| `worker/` | السيرفر (Cloudflare Worker + D1) |

## ١) نشر التطبيق (GitHub Pages)
1. ارفع كل الملفات (ما عدا مجلد `worker`) لمستودع `bsshfi/siraj`.
2. Settings ← Pages ← `main` / root.
3. في Spaceship: سجل CNAME `siraj` ← `bsshfi.github.io`.

## ٢) السيرفر (Cloudflare) — مرة وحدة
1. **D1:** Workers & Pages ← D1 ← Create ← الاسم `siraj` ← Console ← الصق محتوى `worker/schema.sql` ← Execute.
2. **Worker:** Create Worker باسم `siraj-api` ← Edit code ← الصق `worker/worker.js` ← Deploy.
3. **الربط:** Worker ← Settings ← Bindings ← Add ← D1 database ← الاسم `DB` ← اختر `siraj`.
4. **المتغيرات:** Settings ← Variables and Secrets:
   - `VAPID_PUBLIC` و `VAPID_PRIVATE`: مفاتيح الإشعارات (مضافة).
   - `ADMIN_KEY`: نفس قيمة ADMIN_KEY في push-wamdarc.
5. **الجدولة:** Settings ← Trigger Events ← Cron ← `* * * * *`.
6. في `config.js` ضع `VAPID` = المفتاح العام، وتأكد من رابط `API`.

## ٣) مع كل تحديث
- غيّر `VERSION` في `config.js` و `CACHE` في `sw.js` (مثلًا 1.2).
- التطبيق يتحدث لحاله عند المستخدمين أول ما يكون فيه إنترنت.

## إضافة قصة
أضف عنصرًا في `STORIES.push(...)`:
- `{n}` اسم البطل · `{أ|ب}` ولد|بنت · `{dad}` `{mom}` كيف ينادون الأب والأم
- `[[ ... ]]` يظهر فقط مع أطفال مشاركين · `{fr}` أسماؤهم · `{{أ|ب|ج}}` ولد|بنت|أكثر
- قصة مناسبة: `occ: { cal: 'g' أو 'h', m: الشهر, d: [الأيام] }`

المشاهد: `desert` `sea` `space` `garden` `home` `school` `night` `mosque` `park` `market` `road` `mountain` `farm` `kitchen` `rain`

## الخصوصية
رمز العائلة هو مفتاح التشفير. كل بيانات العائلة وسجل القراءة تنشفّر على الجهاز قبل ما توصل السيرفر، والسيرفر ما يعرف إلا بصمة الرمز. نص الإشعار يُكتب على الجهاز نفسه، فأسماء الأطفال ما تمرّ على السيرفر أبدًا.
